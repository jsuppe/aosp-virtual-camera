# Virtual display moved

The display design notes, AIDL definitions and HAL scaffold now live in the
standalone **[jsuppe/aosp-virtual-display](https://github.com/jsuppe/aosp-virtual-display)**
repository. Continue display work there.

The seven original files were extracted with their directory history on
2026-10-24. See the new repository's
[migration record](https://github.com/jsuppe/aosp-virtual-display/blob/main/docs/MIGRATION.md).
The display work remains an incomplete scaffold, not a validated implementation.

Camera release `v0.1.0` and older history retain their original copies; this
forwarding page replaces the display sources only on current camera `main`.
